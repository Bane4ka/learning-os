# F-Strings

## 🧠 Что это

F-string — самый удобный способ вставлять значения переменных в строку.

Используется почти во всех современных Python-проектах.

---

## ⚙️ Как работает

Перед строкой ставится буква `f`.

Внутри фигурных скобок `{}` можно написать переменную или выражение.

```python
name = "Ivan"

print(f"Привет, {name}")
```

Результат

```
Привет, Ivan
```

---

## 💻 Несколько переменных

```python
name = "Ivan"
age = 18

print(f"Меня зовут {name}, мне {age} лет.")
```

Получим

```
Меня зовут Ivan, мне 18 лет.
```

---

## 💻 Можно вычислять выражения

```python
a = 5
b = 3

print(f"{a} + {b} = {a + b}")
```

Получим

```
5 + 3 = 8
```

---

## ❌ Старый способ

```python
print("Привет " + name)
```

Работает, но хуже читается.

---

## ❌ Ещё один старый способ

```python
print("Привет {}".format(name))
```

До сих пор встречается в старом коде, но сейчас чаще используют f-строки.
