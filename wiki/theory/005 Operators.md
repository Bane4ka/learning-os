# Operators

## 🧠 Что это

Операторы позволяют сравнивать значения и выполнять вычисления.

---

## Арифметические

```python
+
-
*
/
//
%
**
```

### Пример

```python
10 // 3
```

↓

```
3
```

```python
10 % 3
```

↓

```
1
```

---

## Операторы сравнения

```python
==
!=
>
<
>=
<=
```

Возвращают bool.

```python
5 > 3
```

↓

```
True
```

---

## Логические

```python
and

or

not
```

---

## Приоритет

```
not

↓

and

↓

or
```

---

## Где используется

Практически в любом if.
