# Random

> [!info] Что такое random
> Модуль для генерации псевдослучайных чисел. Ключевое слово — **псевдо**: компьютер не умеет создавать настоящую случайность, вместо этого используется математический алгоритм. Если запустить программу дважды с одинаковым seed — получишь одинаковую последовательность чисел.

---

## Самые важные функции

### randint()

Возвращает случайное целое число, **включая обе границы**.

```python
import random

x = random.randint(1, 10)   # любое число от 1 до 10 включительно
```

> [!warning] Частая ошибка
> Новички думают, что верхняя граница не входит. **Входит.** `random.randint(1, 10)` может вернуть и `10` тоже.

### choice()

Выбирает случайный элемент из последовательности.

```python
colors = ["red", "blue", "green"]
random.choice(colors)   # например, "blue"
```

### shuffle()

Перемешивает список **на месте** (изменяет исходный список, ничего не возвращает). Используется в карточных играх.

```python
cards = [...]
random.shuffle(cards)
```

### random()

Возвращает дробное число в диапазоне `0 <= x < 1`, например `0.4812391`. Используется в ML, статистике и симуляциях.

---

## Где используется

Игры, генерация тестовых данных, машинное обучение, симуляции — практически везде, где нужна случайность без требований к безопасности.

> [!danger] Когда НЕ использовать random
> Если нужна криптографическая безопасность — банковские приложения, токены, пароли — `random` **не подходит**. Он предсказуем при известном алгоритме и seed. Для таких задач существует модуль `secrets`.

---

## Частые ошибки

> [!warning] Ошибка 1 — граница не включена
> `random.randint(1, 10)` — думают, что `10` не входит. Входит.

> [!warning] Ошибка 2 — забыли импорт
> `NameError: name 'random' is not defined` — забыли `import random` в начале файла.

> [!danger] Ошибка 3 — random для паролей
> Пытаются использовать `random` для генерации паролей или токенов. Нельзя — используйте `secrets`.
