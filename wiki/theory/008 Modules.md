# Modules

## 🧠 Что такое модуль?

Представь, что Python — это огромная мастерская.

Сам язык Python — это пустое помещение.

Чтобы работать, тебе нужны инструменты:

- молоток;
- отвёртка;
- дрель.

В Python роль инструментов выполняют **модули**.

Например:

- random — случайные числа;
- math — математика;
- os — работа с операционной системой;
- pathlib — работа с файлами;
- sqlite3 — база данных.

Без модулей язык был бы очень маленьким.

---

## Почему модули существуют?

Представь, что всё было бы в одном файле.

В Python сейчас миллионы строк кода.

Если бы всё лежало в одном месте:

- было бы невозможно поддерживать;
- невозможно искать;
- невозможно переиспользовать код.

Поэтому код разбивают на отдельные части.

Это называется модульностью.

---

## import

Когда ты пишешь

```python
import random
```

Python НЕ копирует код random в твою программу.

Он:

1. Находит модуль.
2. Загружает его в память.
3. Создаёт объект `random`.
4. Даёт тебе доступ к его функциям.

Именно поэтому потом можно написать

```python
random.randint(...)
```

---

## Почему нужна точка?

```python
random.randint()
```

означает

> Возьми функцию randint из модуля random.

То есть

```
модуль.функция()
```

Очень скоро ты увидишь:

```python
math.sqrt()

os.listdir()

pathlib.Path()

numpy.array()

pandas.read_csv()
```

Все работают одинаково.

---

## Что внутри random?

Это обычный Python-файл.

Внутри находятся десятки функций.

Например

random.py

↓

```
randint()

choice()

shuffle()

random()

uniform()

...
```

---

## Что такое функция?

Пока достаточно понимать так.

Функция — это кусок кода, который уже кто-то написал за тебя.

Ты просто вызываешь его.

Например

```python
print()
```

Это тоже функция.
