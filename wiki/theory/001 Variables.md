# Variables

## 🧠 Что это

Переменная — имя, которое ссылается на объект.

```python
name = "Ivan"
```

---

## Почему это важно

Практически каждая программа использует переменные.

Без них невозможно написать даже Telegram-бота.

---

## Хорошие названия

```python
user_name
user_age
salary
is_admin
```

---

## Плохие

```python
a
aaa
x
test
```

---

## Правила

Используем snake_case.

```python
user_balance
phone_number
```

Не используем:

```python
userBalance
UserBalance
```

---

## Частые ошибки

### Использование переменной до создания

```python
print(age)

age = 18
```

---

### Плохие названия

```python
a = 100
```
