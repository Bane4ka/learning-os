# Data Types

## 🧠 Что это

Тип данных определяет, какую информацию хранит объект.

---

## int

```python
age = 18
```

---

## float

```python
height = 1.82
```

---

## str

```python
name = "Ivan"
```

---

## bool

```python
is_student = True
```

---

## Проверить тип

```python
print(type(name))
```

---

## Преобразование

```python
int()

float()

str()

bool()
```

---

## Частые ошибки

```python
"18" + 18
```

Ошибка.

Нужно привести тип.
