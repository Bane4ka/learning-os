# Списки (list)

> [!info] Что такое список
> Список (`list`) — структура данных для хранения нескольких значений в одном объекте, вместо создания кучи отдельных переменных (`a`, `b`, `c`, `d`...).
>
> ```python
> numbers = [10, 20, 30, 40]
> ```

Списки используются практически везде: список игроков, товаров, задач, пользователей, изображения (матрицы пикселей), датасеты в ML. Любая программа постоянно работает со списками.

---

## Создание списка

```python
tasks = []                          # пустой
numbers = [1, 2, 3, 4, 5]           # числа
names = ["Ivan", "Alex", "Kate"]    # строки
data = ["Ivan", 18, True, 179]      # Python разрешает разные типы в одном списке
```

## Индексы

У каждого элемента есть номер, начиная с нуля:

```
0    1    2    3
↓    ↓    ↓    ↓
["A","B","C","D"]
```

```python
letters = ["A", "B", "C"]
print(letters[0])    # A
print(letters[-1])   # C — последний элемент
print(letters[-2])   # B — предпоследний
```

> [!tip] Отрицательные индексы
> `[-1]` — последний элемент, `[-2]` — предпоследний. Используются очень часто, особенно когда длина списка заранее неизвестна.

## Изменение элемента

```python
numbers = [5, 7, 9]
numbers[1] = 100
print(numbers)   # [5, 100, 9]
```

## Основные методы

| Метод | Что делает |
|---|---|
| `append(x)` | Добавляет элемент в конец — самый используемый метод |
| `remove(x)` | Удаляет первый элемент **по значению** |
| `pop(i)` | Удаляет элемент **по индексу** (без аргумента — удаляет последний) |
| `len(list)` | Возвращает количество элементов |
| `x in list` | Проверяет наличие значения, без ручного перебора |
| `list[i]` | Получить элемент по индексу |

```python
tasks = []
tasks.append("Изучить Python")   # ["Изучить Python"]
tasks.remove("Изучить Python")   # []

numbers = [5, 8, 10]
numbers.pop(1)     # [5, 10]
numbers.pop()      # удалит последний, если индекс не указан
```

## Перебор списка

```python
tasks = ["A", "B", "C"]

for task in tasks:      # ✅ правильный способ в 95% случаев
    print(task)

for i in range(len(tasks)):   # так делают, только если реально нужен номер элемента
    print(tasks[i])
```

`range(5)` создаёт последовательность `0, 1, 2, 3, 4` — отсюда `for i in range(len(tasks))` даёт индексы `0..len-1`.

> [!tip] for или while
> `while` — когда заранее неизвестно количество повторений ("пока пользователь не выйдет"). `for` — когда нужно пройти по готовой коллекции ("все задачи", "все пользователи"). Для списка почти всегда выбирают `for`.

## Частые ошибки

> [!danger] IndexError — обращение за пределы списка
> ```python
> tasks[3]   # если элементов меньше четырёх → IndexError
> ```

> [!danger] ValueError — remove() несуществующего элемента
> ```python
> tasks.remove("Python")   # если элемента нет в списке → ValueError
> ```

> [!warning] Путаница индекса и элемента в for
> ```python
> for i in tasks:
>     print(tasks[i])   # ❌ i — это уже элемент списка, а не индекс
> ```
> Правильно: `for task in tasks: print(task)`, либо `for i in range(len(tasks)): print(tasks[i])`.
