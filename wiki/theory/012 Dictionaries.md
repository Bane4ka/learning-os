# Dictionaries (dict)

> [!info] Что это
> Список (`list`) хранит значения по номеру позиции. Словарь (`dict`) хранит значения по **ключу** — произвольному имени, а не порядковому номеру.
>
> ```python
> user = {
>     "name": "Ваня",
>     "age": 19,
>     "city": "Москва"
> }
> ```
>
> Это не "список с именами вместо номеров" — принципиально другая структура. Список — когда важен порядок. Словарь — когда важна связь "по этому ключу лежит вот это значение".

---

## Доступ к значениям

```python
print(user["name"])   # Ваня
```

> [!danger] KeyError
> ```python
> print(user["email"])   # ❌ KeyError: 'email', если ключа нет
> ```
> Безопасный способ:
> ```python
> print(user.get("email"))                  # None, без падения
> print(user.get("email", "нет данных"))    # свой запасной вариант
> ```

> [!tip] Правило выбора []  или .get()
> Если не уверен, что ключ точно есть — `.get()`. Если ключ обязан быть по логике программы (иначе это баг) — обычные `[]`, пусть падает явно, а не тихо подставляет `None`.

---

## Добавление и изменение

```python
user["email"] = "vanya@example.com"   # добавили новый ключ
user["age"] = 20                       # изменили существующий
```

Один и тот же синтаксис для добавления и изменения — если ключ есть, перезапишется, если нет — создастся.

---

## Удаление

```python
del user["city"]              # удалить по ключу, KeyError если ключа нет
removed = user.pop("age")     # удалить и получить значение, .pop("age", None) — безопасно
```

---

## Проверка наличия ключа

```python
if "email" in user:
    print("Email есть")
```

> [!warning] `in` для словаря проверяет ключи, не значения
> Частая ошибка новичков — ожидать, что `in` найдёт значение среди `.values()`. По умолчанию `in` смотрит только на ключи.

---

## Перебор словаря

```python
for key in user:                  # по ключам (по умолчанию)
    print(key, user[key])

for key, value in user.items():   # сразу пары ключ-значение — предпочтительный способ
    print(key, value)

for value in user.values():       # только значения
    print(value)
```

В реальном коде почти всегда используют `.items()`, когда нужны и ключ, и значение — это яснее, чем `user[key]` внутри цикла.

## Вложенные словари

```python
contacts = {
    "Ваня": {"phone": "+7900...", "email": "vanya@example.com"},
    "Аня": {"phone": "+7911...", "email": "anya@example.com"}
}

print(contacts["Ваня"]["phone"])
```

Именно так будет устроен сегодняшний проект — словарь словарей.

## Частые ошибки

> [!danger] Обращение по несуществующему ключу без проверки
> ```python
> print(user["email"])   # падение, если email не задан
> ```
> Либо `.get()`, либо `if "email" in user` заранее.

> [!warning] Путаница `in` для списка и для словаря
> Для списка `in` ищет **значение** среди элементов. Для словаря — **ключ**. Разные операции с одинаковым синтаксисом.

> [!warning] Изменяемый словарь как значение по умолчанию в функции
> Та же ловушка, что и со списками (см. [[011 Functions]]):
> ```python
> def add_contact(contacts={}):   # ❌ словарь общий для всех вызовов функции
>     ...
> ```
