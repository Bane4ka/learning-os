# Python Philosophy

## 🧠 Что это

Python — язык общего назначения.

Его главная идея — писать понятный код.

---

## ⚙ Основные принципы

- Простота лучше сложности.
- Читаемость важнее краткости.
- Код пишется один раз, читается сотни раз.

---

## 💼 Где используется

- Backend
- ML
- Data Science
- AI
- Telegram-боты
- Автоматизация
- Парсинг сайтов

---

## Почему именно Python

Практически весь современный ML написан именно вокруг Python.

Большинство библиотек сначала появляются именно для него.

---

## Самое важное

Программист не запоминает весь язык.

Он умеет находить решение задачи.
