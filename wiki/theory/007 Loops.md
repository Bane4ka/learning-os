# Loops

## 🧠 Что такое цикл

Цикл позволяет выполнять один и тот же код несколько раз.

Без циклов пришлось бы писать:

print(...)
print(...)
print(...)
print(...)

---

## while

Выполняется, пока условие истинно.

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Получим:

1
2
3
4
5

---

## Бесконечный цикл

```python
while True:
    ...
```

Используется очень часто.

Выход:

```python
break
```

---

## continue

Пропускает текущую итерацию.

---

## break

Полностью завершает цикл.

---

## Когда использовать while

Когда заранее неизвестно,
сколько раз повторится действие.

Примеры:

- Авторизация
- Банкомат
- Игры
- Меню программы
