# Learning OS

Личная система обучения и база знаний в Obsidian. Цель: ML Engineer, первый этап — Python для анализа данных ([roadmap.sh](https://roadmap.sh/data-analysis)).

Основана на идее LLM Wiki: **человек пишет исходный код знаний, ИИ помогает проверять и собирать их.**

## Модель

```
raw/ (источники) → wiki/ (проверяемое знание) ← learning/ (моё понимание) → projects/ (результат)
```

| Папка | Что внутри | Кто пишет |
|---|---|---|
| `raw/` | Исходные источники (документация, главы, статьи) | человек, не редактируется |
| `wiki/` | Скомпилированные заметки со ссылками на источники, `wiki/sources/` — карточки источников, `wiki/theory/` — теория с предыдущего этапа | ИИ по источникам |
| `learning/` | Мои заметки своими словами | только человек |
| `projects/` | Проекты с кодом и ревью | человек, ИИ ревьюит |
| `log/` | Журналы `ingest.md` и `ai-usage.md`, только на добавление | человек + ИИ |
| `llm/` | Промпты и сохранённые ответы | человек |
| `meta/` | Roadmap, принципы, карты, Bug Journal | человек |
| `templates/` | Шаблоны заметок | человек |

## Рабочий цикл на одну тему

1. Источник в `raw/` → режим **Ingest** (карточка в `wiki/sources/`).
2. Своя заметка в `learning/` без подсказок.
3. Режим **Tutor**: ИИ задаёт вопросы, не переписывает текст.
4. Режим **Examiner**: проверка знаний по одному вопросу.
5. Режим **Compile**: справочная заметка в `wiki/` со ссылками на источники.
6. Проект в `projects/` → режим **Reviewer**.

Правила для ИИ-агента: [`AGENTS.md`](AGENTS.md). Структура и соглашения: `meta/Vault System.md`.
