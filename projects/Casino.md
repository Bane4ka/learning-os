# Casino

## 📌 Задача

Игра в казино: ставка, случайное число, выигрыш/проигрыш, возможность сыграть ещё раз.

## 💻 Код (текущая, исправленная версия)

```python
import random
Balance=100000
while input('Хотите сыграть? (да/нет): ').lower()=='да':
    Bet=int(input(f'''
    Добро пожаловать в казино!
    Ваш баланс:{Balance}
    Выбрать ставку: '''))
    if Bet>Balance:
        print(f'''
        Недостаточно средст на балансе
        Ваш баланс:{Balance}''')
    if Bet<=0:
        print(f'''
        Ставка не может быть меньше или равна нулю'
        Ваш баланс:{Balance}''')
    if Bet>0 and Bet<=Balance:
        rand=random.randint(1, 10)
        if rand==7:
            Balance=Balance+Bet*3
            print(f'''
            Выпало число - {rand}
            Поздравляем вы выиграли (x3)!
            Ваш выигрыш {Bet*3}
            Ваш баланс:{Balance}''')
        elif rand==3:
            Balance=Balance+Bet*2
            print(f'''
            Выпало число - {rand}
            Поздравляем вы выиграли (x2)!
            Ваш выигрыш {Bet*2}
            Ваш баланс:{Balance}''')
        else:
            Balance=Balance-Bet
            print(f'''
            Выпало число - {rand}
            К сожалению вы проиграли, повезет в следующий раз
            Ваш баланс:{Balance}''')
print('До встречи, приходите еще!')
```

## 📝 История правок (учебная ценность важнее самого кода)

**Версия 1 (первая проверка):** содержала реальный логический баг — цепочка `if rand==7 / if rand==3 / else` вместо `if/elif/else`. При выигрыше `rand==7` код всё равно проваливался в `else` следующего блока и **списывал ставку вместо начисления выигрыша**. Плюс сообщение о проигрыше было скопировано с текстом "Поздравляем вы выиграли".

**Версия 2 (текущая):** баг исправлен — `elif` расставлен верно, добавлена валидация (`Bet>Balance`, `Bet<=0`), добавлен цикл повторной игры через `while`. Это первый проект, где фидбек по code review был не просто прочитан, а реально применён — зафиксировано как показатель прогресса.

**Осталось на будущее:** `Balance`, `Bet`, `rand` — не всегда snake_case полностью выдержан по всему файлу, три отдельных `if` (`Bet>Balance`, `Bet<=0`, `Bet>0 and Bet<=Balance`) можно было бы собрать в один `if/elif/else`, сейчас это работает, но избыточно многословно.
