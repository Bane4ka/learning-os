# Sorting Algorithms

## 📌 Задача

Реализовать три алгоритма сортировки руками, сравнить их со встроенным `sorted()`. Продолжение [[Search Algorithms]] — сортировка нужна была там как предпосылка, здесь становится темой самой по себе.

## ⚙️ Что реализовать

1. `bubble_sort(arr)` — с оптимизацией: флаг `swapped`, если за проход не было ни одного обмена — выйти раньше
2. `insertion_sort(arr)` — без использования встроенных `sorted`/`.sort()`
3. `merge(left, right)` — слияние двух отсортированных списков в один
4. `merge_sort(arr)` — рекурсивно, используя `merge()`

## 🧪 Сравнение на практике

- Список из 1000 **случайных** чисел (`random.sample` или `random.randint` в цикле) — прогнать через все три твои реализации + `sorted()`, засечь время через `time.time()` или `time.perf_counter()`
- Тот же список, но **уже отсортированный** — прогнать `bubble_sort` с оптимизацией и без (временно закомментируй `swapped`), сравнить число проходов. Ожидание: с оптимизацией — 1 проход, без — n проходов, хотя результат идентичен
