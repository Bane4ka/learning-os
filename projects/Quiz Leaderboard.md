# Quiz Leaderboard

## 📌 Задача

CLI-таблица результатов квиза. Новый проект, не связан с [[Expense Tracker]] и остальными — намеренно другой домен, чтобы не копировать структуру бездумно.

Функционал:
- **Добавить результат** — имя игрока + очки
- **Показать топ-3** — три лучших результата
- **Показать всех** — весь список результатов
- **Выйти**

## ⚙️ Архитектурные требования (зачем именно tuples и sets)

- `players_seen` — **set** имён игроков, которые уже играли в этой сессии. Правило: **один и тот же игрок не может добавить результат дважды за сессию** — если имя уже в `players_seen`, вывести сообщение и не добавлять
- `scores` — **list of tuples**: `[("Ваня", 50), ("Аня", 80)]`. Каждая запись — `(name, score)`, кортеж, потому что запись о результате логически зафиксирована и не должна меняться после добавления
- `get_top(scores, n)` — возвращает `n` лучших записей, отсортированных по очкам (подсказка: у `sorted()` есть параметр `key`, и можно сортировать список кортежей по второму элементу каждого кортежа — погугли `key=lambda x: x[1]`, если не видел `lambda` раньше, просто используй как готовый рецепт, само устройство `lambda` разберём отдельно позже)
- Ввод очков — снова `try/except ValueError` с retry через `while True`, как в [[Expense Tracker]] — это должно быть уже автоматическим, без подсказок

## Меню

```
1. Добавить результат
2. Показать топ-3
3. Показать всех
4. Выйти
```
