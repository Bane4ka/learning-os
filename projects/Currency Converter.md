# Currency Converter

## 📌 Задача

Перевести введённое количество рублей в доллары по фиксированному курсу.

## 💻 Код

```python
from math import *
dollar_price = 77.0
rubles_count=float(input('Введите количество рублей: '))
dollars_count=round(rubles_count/dollar_price, 2)
print(f'В {rubles_count} рублях {dollars_count} долларов')
```

## 📝 Заметки

`from math import *` — модуль `math` импортирован целиком, но в коде не используется ни одна его функция (`round()` — встроенная функция Python, не из `math`). Это wildcard-импорт "на всякий случай", а не осознанное решение. Проблема wildcard-импорта: он тащит в код все имена из модуля разом, и если где-то дальше появится своя переменная с именем, случайно совпадающим с именем из `math` (например, `pi` или `e`) — она будет незаметно перезаписана. В реальном коде импортируют только то, что реально нужно: `from math import sqrt`, а лучше вообще не импортировать то, чем не пользуешься.

Также у файла на диске двойное расширение: `currency_converter.py.py` — опечатка при создании файла, стоит переименовать.
