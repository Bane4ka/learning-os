# Guess Number

## 📌 Задача

Пользователь угадывает число, программа подсказывает "больше/меньше".

## 💻 Код

```python
const=57
user_number=int(input('Введите число: '))
while user_number!=const:
    if user_number>const:
        print('Меньше')
    elif user_number<const:
        print('Больше')
    user_number=int(input('Введите число: '))
print('Примите мои поздравления, вы разгадали число компьютера!')
```

## 🔗 Применённая теория

- [[006 Conditions]] — `elif` использован правильно
- [[007 Loops]] — `while` с условием выхода по совпадению

## 📝 Заметки

Логика чистая, `elif` — то, чего не хватало в BMI Calculator и не хватало в старой версии Casino. Единственное: файл называется `random.py`, но модуль `random` тут даже не импортирован — число `57` жёстко зашито в `const`. Это не баг (программа работает), но два момента на будущее:

1. Имя файла `random.py` **шадовит** стандартный модуль `random` — если в этой же папке когда-нибудь понадобится `import random`, Python попытается импортировать сам этот файл вместо стандартной библиотеки. См. [[008 Modules]].
2. Естественное развитие проекта — заменить `const=57` на `random.randint(1, 100)`, чтобы "компьютер" загадывал число сам, а не всегда одно и то же. Хорошее упражнение после темы [[009 Random]] — можешь вернуться и доработать.
