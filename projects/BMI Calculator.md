# BMI Calculator

## 📌 Задача

Посчитать индекс массы тела и вывести категорию.

## 💻 Код

```python
Height=(int(input('Введите ваш рост(см): ')))/100
Weight=int(input('Введите ваш вес(кг)'))
bmi=round(Weight/(Height**2),2)
if bmi<=18.5:print(f'Ваш ИМТ - {bmi}. У вас недостаток веса')
if 18.5<=bmi<=24.5:print(f'Ваш ИМТ - {bmi}. У вас нормальный вес')
if 25.0<=bmi<=29.9:print(f'Ваш ИМТ - {bmi}. У вас избыточный вес')
if 30.0<=bmi<=34.9:print(f'Ваш ИМТ - {bmi}. У вас ожирение 1 степени')
if 35.0<=bmi<=39.9:print(f'Ваш ИМТ - {bmi}. У вас ожирение 2 степени')
if bmi>=40:print(f'Ваш ИМТ - {bmi}. У вас ожирение 3 степени(морбидное)')
```

## 📝 Заметки

Логика корректна — диапазоны не пересекаются, поэтому багов, как в Casino, здесь нет. Но стилистически правильнее использовать `if/elif`, а не пять независимых `if`: сейчас Python проверяет **все шесть условий подряд** каждый раз, даже если результат уже найден в первом. При `elif` он бы останавливался на первом совпадении — быстрее и яснее читается как "одно из шести", а не "шесть независимых проверок".

Также нет проверки на отрицательный или нулевой рост/вес — если пользователь ошибётся при вводе, будет `ZeroDivisionError` или бессмысленный отрицательный ИМТ. Не обязательно чинить прямо сейчас (до [[015 Exceptions]] ещё дойдём), но держи в голове.

`Height`, `Weight` — снова не snake_case.
