## 🧬 Learning OS

Модель: `raw/` (источники) → `wiki/` (проверяемое знание) ← `learning/` (моё понимание) → `projects/` (результат).
Правила для ИИ и режимы работы (Ingest, Compile, Tutor, Reviewer, Examiner): [[AGENTS]].
Точка входа: [[index]] в `wiki/`.
Старая теория лежит в `wiki/theory/` и считается слоем wiki без источников — перерабатывается по одной теме через цикл, не удаляется.

## 🏷 Система тегов

Иерархические теги вида `домен/поддомен`:

- `python/core` — базовый синтаксис языка (переменные, циклы, функции...)
- `python/stdlib` — стандартная библиотека (`random`, `math`, `os`...)
- `roadmap`, `career`, `bugs`, `misc`, `ai-agents` — не-Python темы
- `wiki/source`, `wiki/note`, `learning` — Learning OS

Когда дойдёшь до Git/Backend/Data/ML — заводи по той же логике: `git/basics`, `backend/fastapi`, `data/pandas`, `ml/regression` и т.д.

---

## 🪜 Поле `level` (глубина темы)

- `level: 1` — фундамент (переменные, условия, циклы, функции)
- `level: 2` — следующий слой (модули, random, списки)
- Дальше при переходе на ООП/backend можно продолжать нумерацию (`level: 3`, `4`...) — это твоя "ветка развития" по вертикали.

---

## 🧩 Поле `type` (роль заметки)

- `type: theory` — объясняет концепцию (в новых заметках из шаблона; у старых `000`–`019` этого поля нет, это допустимо — поле добавится при переработке темы)
- `type: project` — код + ревью конкретного проекта
- `type: moc` — карта/индекс, ссылки на другие заметки
- `type: log` — журнал (Bug Journal, отчёты)
- `type: source` — карточка источника
- `type: learning` — твоя заметка своими словами
- `type: wiki` — скомпилированная заметка со ссылками на источники
- `type: note` — всё остальное (misc)

## 🔗 Как связаны теория и проекты

Каждая теоретическая заметка в конце содержит:

```
## 🚀 Мини-проект
[[Название Проекта]]
```

А каждая карточка проекта в frontmatter содержит:

```yaml
theory:
  - "[[Название Темы]]"
```

Это и есть "ветка развития" — от теории к практике и обратно, видно в обе стороны через backlinks.

## ➕ Как добавлять новое

1. Новый источник → кладёшь файл в `raw/`, потом `Режим Ingest` (карточка в `wiki/sources/` из `templates/Source Card Template.md`).
2. Своё понимание → `templates/Learning Note Template.md` в `learning/`, пишешь сам.
3. Скомпилированная заметка → `templates/Wiki Note Template.md` в `wiki/` (только через `Режим Compile`).
4. Новая теория по старому формату → `templates/Theory Template.md` в `wiki/theory/`, с нумерацией.
5. Новый проект → `templates/Project Template.md` в `projects/`.
6. Теория и проект ссылаются друг на друга в обе стороны. Новую тему добавляй в индекс `wiki/theory/Python.md`.

## ⚙️ Настройки Obsidian

- **Templates → Template folder location** → `templates` (уже настроено).
- **Files & Links → Automatically update internal links** → включено (`alwaysUpdateLinks`), поэтому переименование папок в Obsidian не ломает ссылки.
- **CSS snippets** → `knowledge-garden` должен быть включён.
