# Принципы обучения

## 🎯 Главная цель

Стать инженером, который умеет решать реальные задачи с помощью программирования и искусственного интеллекта.

---

## Основные правила

### 1. Теория без практики = забытая теория

Каждая тема должна закончиться кодом.

---

### 2. Один день — один шаг

Лучше писать код каждый день по 2 часа, чем один раз в неделю по 14.

---

### 3. Любая ошибка — обучение

Ошибки не удаляются.

Они записываются в [[Bug Journal]].

---

### 4. Код важнее просмотра видео

Соотношение должно быть примерно:

20% теория

80% практика

---

### 5. Не запоминать — понимать

Главная задача — понять механизм.

Синтаксис всегда можно посмотреть.

---

### 6. Любой новый навык должен отвечать на вопрос

> Какую задачу теперь я могу решить?
